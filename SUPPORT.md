# Support

Margin is an open-source tool maintained by the OpenProse team without a
guaranteed response time or support service-level agreement.

Before opening an issue:

1. Check the [installation guide](Docs/INSTALLATION.md) and
   [CLI guide](Docs/CLI.md).
2. Search existing issues for the same behavior.
3. Confirm the behavior on the latest release when practical.

Use a GitHub bug report for reproducible defects and a feature proposal for
product ideas. Use GitHub Discussions, if enabled, for open-ended usage
questions. Do not use public issues for security or conduct reports; follow
[`SECURITY.md`](SECURITY.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
